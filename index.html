UN CANARD QUI RESTE SUR TON ÉCRAN

Pas sur le site. Sur ton bureau. Il continue de flotter même quand tu quittes la page.

Si rien ne se passe, le navigateur intégré peut bloquer l'ouverture. Ouvre Finder → Applications → "Canard de bureau", ou tape Cmd+Espace puis "canard".
